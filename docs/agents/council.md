# Research and council

Use the repository's `.altana/altana.toml` through `ALTANA_CONFIG`.
`mise run council:review -- PATH` reviews a plan with Fable, Astra and Carbon.
`mise run council:check` checks the configuration and available harnesses.
All council members are read-only, without permission bypass or inherited MCP tools.
Carbon's effort is encoded in its model identifier. Other efforts are explicit.
The caller owns synthesis and records missing responses, statuses and evidence in GitHub.

Use Sol medium for research. Native Sol hands may return reports to the lead for saving and publication.
No implementation is authorized by a research result or council vote.
Smoke-test each harness before substantive work. Capture results outside tracked product files.
Allow one transient retry within a ten-minute run deadline. No model substitution is pre-authorized.
Preserve failures and request a decision when the named harness cannot run.

The installed Altana version during setup was 0.9.3. Use `harness run`, not the removed `delegate` command.
Use primary sources and dated revisions when comparing Apple Container with Kina.
