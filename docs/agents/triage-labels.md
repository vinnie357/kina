# Triage labels

| Role | Label |
| --- | --- |
| Needs evaluation | `needs-triage` |
| Missing information | `needs-info` |
| Fully specified agent work | `ready-for-agent` |
| Requires human work | `ready-for-human` |
| Will not be actioned | `wontfix` |

`deferred` preserves work outside the current effort. Wayfinder issues use only `wayfinder:*` labels.
